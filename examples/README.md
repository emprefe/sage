# SAGE reference examples

These examples are intentionally small and independent of the CMS projects.

- `php/` — framework-free PHP Core/image adapter with a vanilla JavaScript browser demo for PNG, JPEG, and WebP.
- `dart/` — reusable Dart v0.02 Core package and CLI. Image UI and format adapters are a later layer.

All examples use the shared JSON vectors under `tests/vectors/`.
